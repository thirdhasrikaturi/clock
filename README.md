# Time Utility App

A web-based Time Utility App that provides a Digital Clock and Stopwatch. 
The project is developed using HTML, CSS, and JavaScript.

## Live Demo

https://tsclock.netlify.app/

## Features

### Digital Clock
- Displays the current time in hours, minutes, and seconds.
- Supports AM/PM format.
- Updates automatically every second.

### Stopwatch
- Start the stopwatch.
- Stop the stopwatch.
- Reset the stopwatch.
- Displays elapsed time in hours, minutes, and seconds.
